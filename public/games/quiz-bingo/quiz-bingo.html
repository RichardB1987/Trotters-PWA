Tokens & Modifiers

Spending Tokens

Start with 2 tokens. Earn +1 token for a completed line or answering right on an already-completed category colour.

  • Respin · 1 Token (first come, first served) — spin again for a new category. Unrevealed question goes back in the pool; locked modifier stays.
  • Wild Colour · 2 Tokens (first come, first served) — counts the spun category as any colour on your card.
  • Mute · 3 Tokens — mute one opponent for the round. No back-to-back mutes on the same player.
Modifiers

Triggers every 4–6 new spins (respins don't count), with on-screen and voice callouts. Clears on Next Round; stays locked across a Respin.

  • Token Rush — right = +2 tokens & mark square.
  • Danger Zone — right = mark square; wrong = −1 token (or −1 square if at 0 tokens).
  • Double or Nothing — right = +2 tokens & mark square; wrong = lose all tokens (squares safe).
